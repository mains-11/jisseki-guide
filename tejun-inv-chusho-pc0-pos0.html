ホーム/申請マイページの入力手順/中小企業｜PC なし／POS なし

インボイス枠｜中小企業｜PC なし／POS なし

申請マイページでの操作手順です。画面の表示にあわせて、上から順に進めてください。

インボイス枠中小企業パソコン・タブレット等 なしPOSレジ等 なし
①書類を添付して送信貴社での作業
②内容の確認弊社での作業
③事務局へ提出貴社での作業
進める前に

添付するファイルは、先にすべて手元にそろえておくとスムーズです。必要な書類はこちら。

  1. 申請マイページにログインする

    申請マイページを開く

    推奨環境

    Windows の Microsoft Edge または Google Chrome の最新版でご利用ください。

    1. ログイン画面で、紫色の「GビズIDでログイン」を押す
    2. GビズIDのアカウントとパスワードを入力する
    3. 画面の案内にしたがって二要素認証を行う
    4. ログイン後、「申請者メニュー」→「実績報告情報編集」へ進む

  2. 説明画面を確認する

    1. 画面内の研修動画のリンクをクリックする
    2. 動画を最後まで視聴したら、ブラウザの「戻る」で説明画面に戻る
    3. 「動画を視聴して内容を理解しました」のチェックを入れる

    次へ

  3. 請求書を添付する

    1
    1_請求明細書_事業者名

    次へ

  4. 支払方法を選択する

    • 銀行振込
    • クレジットカード払い

    次へ

  5. 支払証憑を添付する

    2
    2_支払証憑_事業者名

    次へ

  6. その他資料を確認する

    添付が必要な資料はありません。画面の内容を確認して、そのまま次へ進みます。

    次へ

  7. ソフトウェア証憑を添付する

    3
    3_ソフトウェア証憑_事業者名

    次へ

  8. ハードウェア導入情報（パソコン・タブレット等）

    パソコン・タブレット等の導入はないため、「いいえ」を選びます。添付は不要です。

    • はい
    • いいえ

    次へ

  9. ハードウェア導入情報（POSレジ等）

    POSレジ等の導入はないため、「いいえ」を選びます。添付は不要です。

    • はい
    • いいえ

    次へ

  10. 口座情報を添付する

    4
    4_口座情報_事業者名

    次へ

  11. 口座情報を入力する

    添付したPDFを開き、そこに書かれている内容を画面の項目へ入力します。

    口座名義は事前に確認を

    金融機関に登録されている名義と完全に一致している必要があります。スペース・濁点・半濁点にご注意ください。

    項目入力のしかた
    金融機関名画面を下にスクロールし、紫色の「検索」ボタンをクリック → 全角カタカナで入力 → 入力欄の外をクリック →「検索」→ 候補から選択
    文字を入力している間は「検索」ボタンを押せません。
    支店名金融機関名と同じ手順で検索して選択します。
    口座種別・口座番号通帳または口座情報の画面のとおりに入力します。
    口座名義（カナ）金融機関の登録どおりに入力します。

    次へ

  12. 実績報告の入力を完了する

    入力確認画面で内容を確認し、画面の一番下のボタンを押します。

    実績報告入力完了

    ここで①は完了です

    入力内容が弊社に引き継がれます。弊社での確認が終わりましたら、③「事務局への提出」の操作をご案内します。
