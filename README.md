# デジタル化・AI導入補助金｜実績報告ガイド

株式会社M'AINS がお客様向けにご案内する、実績報告の手引きサイトです。

交付決定後の手続きをご案内します。GitHub Pages で公開する静的サイト（HTML / CSS / JavaScript のみ）です。

---

## ファイル構成

```
（リポジトリ直下）
├── index.html                      はじめに（トップ）
├── jisseki.html                    必要書類の一覧
├── jisseki-*.html                  書類ごとの説明（7ページ）
├── tejun.html                      入力手順の選択ページ
├── tejun-tsujo.html                通常枠の入力手順
├── tejun-inv-*.html                インボイス枠の入力手順（8パターン）
├── tejun-teishutsu.html            事務局への提出
├── 404.html                        存在しないページ用
├── assets/
│   ├── style.css                   デザイン（配色・文字・レイアウト）
│   └── site.js                     スマホ用メニュー／手順の絞り込み
├── tools/
│   └── build.py                    全ページを生成するスクリプト（任意）
├── robots.txt                      検索エンジンにのせない設定
└── .nojekyll                       GitHub Pages の変換を無効化
```

## 文章やデザインを直したいとき

### 少しだけ直す場合

該当の `.html` を GitHub 上で直接編集してください。
配色や文字サイズを変えるときは `assets/style.css` の先頭にある `:root { ... }` の
色コードを書き換えれば、全ページにまとめて反映されます。

| 変数名 | 使われている場所 |
| --- | --- |
| `--navy` | 見出しの下線、手順番号、ボタン |
| `--seal` | 注意書き、添付ファイルの番号 |
| `--paper` | ページ全体の背景色 |
| `--ink` | 本文の文字色 |

### まとめて直す場合

`tools/build.py` に全ページの文章が入っています。編集後、手元のパソコンで

```
python3 tools/build.py
```

を実行すると、すべての HTML が上書き生成されます。生成された HTML を
コミットしてください。（Python が入っていない場合は HTML を直接編集して構いません。）

## 公開前に必ず確認すること

- [ ] 書類ごとのページの内容が、最新の公募要領・事務局の案内と一致しているか
- [ ] 添付ファイル名の番号（`1_請求明細書_事業者名` など）が自社の運用と一致しているか
- [ ] 中小企業区分での「その他資料」欄の扱い（現在は「添付不要」としています）
- [ ] 問い合わせ先の記載を追加するかどうか

制度の内容は年度ごとに変わります。公開後も、公式サイトの更新にあわせて見直してください。
